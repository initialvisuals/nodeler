# Nodeler

A Python **node playground** for assorted “nodely” experiments — graph editor scraps, mesh-network simulation (self-healing / redirection), and a rock-climbing route sketch.

Part of the [Initial Visuals](https://github.com/initialvisuals) toolkit / game lab.

### Status

Early / exploratory. Multiple experiments live in one tree. Expect rough structure and unfinished ideas.

### What’s in the box

| Path | What |
|------|------|
| `main.py` | Entry |
| `nodes.py` / `connection.py` | Node + edge primitives |
| `console.py` / `toolbar.py` / `property_explorer.py` | UI chrome |
| `rockclimbingroute.py` | Climbing-route experiment |
| `config.py` | Config |
| `backups/` | Older snapshots |

### Quick start

```bash
python main.py
```
